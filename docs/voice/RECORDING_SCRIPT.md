# Annabeth's Magical Animal Hospital - voice recording script

**How to record:** read each line exactly as written, in a warm, cheerful storybook voice for a kindergartener. Leave a clean 2-second silence between lines (that gap is how I cut the files apart). If you flub a line, stay silent for 2 seconds and read it again. Record one file per section, and send them in order. Words in *(parentheses notes)* are directions, not spoken. Lines marked **RETIRED - do not record** are left in place only so the numbering stays stable for reference; skip them.

**Updated September 26, 2026:** this is the complete, current script — regenerate the whole pack from this file rather than patching the old one.
